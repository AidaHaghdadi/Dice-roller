# 🎲 Python Dice Roller


## 📌 About the Project

This project contains two Python programs that simulate rolling dice. It started with a basic dice roller and was gradually improved by adding new features.

## ✨ Features

### 1. Basic Dice Roller — `dice_roller.py`
- Roll two six-sided dice.
- Choose whether to roll again or exit the program.
- Handle invalid user inputs.

### 2. Multiple Dice Roller — `dice_roller_multiple.py`
- Choose how many dice to roll.
- Generate a random result for each die.
- Validate the number of dice entered by the user.
- Count successful dice rolling rounds.

## 🛠️ Technologies Used

- **Python**
- `random` module
- `while` loops and `for` loops
- Conditional statements
- Lists
- Exception handling (`try/except`)
- User input and output

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/AidaHaghdadi/Dice-rooling-game
```

Navigate to the project directory:

```bash
cd dice-roller
```

Run the basic dice roller:

```bash
python dice_roller.py
```

Or run the multiple dice roller:

```bash
python dice_roller_multiple.py
```
